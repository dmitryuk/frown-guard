# Frown Guard (Контроль хмурости)

Приложение на Python + MediaPipe, которое отслеживает мимику лица (сведение и опускание бровей, складки на лбу) через веб-камеру. При хмурости оно мгновенно выводит поверх всех окон полупрозрачное уведомление-предупреждение, которое автоматически исчезает, когда лицо расслабляется.

## Архитектура проекта

Проект разделен на следующие компоненты для обеспечения чистоты кода, модульности и простоты сопровождения:

1. **`detector.py` (Анализатор лица):**
   - Инкапсулирует логику MediaPipe Face Mesh.
   - Извлекает ключевые 3D-координаты бровей и глаз.
   - Рассчитывает нормализованные метрики сведения бровей (`sep_ratio`) и высоты бровей (`height_ratio`).
   - Содержит алгоритм калибровки и вычисления уровня хмурости.

2. **`overlay.py` (Плавающее уведомление):**
   - Легковесное, безрамочное (`overrideredirect`) окно на Tkinter.
   - Отображается поверх всех окон (`attributes("-topmost", True)`) с регулируемой прозрачностью (`alpha`).
   - Поддерживает мгновенный показ (`deiconify`) и скрытие (`withdraw`).

3. **`app.py` (Главная панель управления):**
   - Основной графический интерфейс на Tkinter с современным темным дизайном.
   - Отображает видеопоток с камеры в реальном времени с наложенными ориентирами лица.
   - Содержит элементы управления:
     - Кнопки калибровки ("Спокойное лицо" и "Нахмуренное лицо").
     - Слайдер чувствительности.
     - Сохранение/загрузку конфигурации в JSON.
     - Логику запуска видеозахвата в отдельном фоновом потоке, чтобы интерфейс оставался отзывчивым.

4. **`main.py` (Точка входа):**
   - Инициализирует и запускает приложение.

## Стандарты программирования

- **Типизация:** Все функции и методы должны быть полностью типизированы с помощью Python Type Hints (`typing`).
- **Обработка ошибок:** Надежный захват ошибок веб-камеры (если камера отключена или занята другим процессом) с показом понятного сообщения пользователю.
- **Локализация:** Интерфейс приложения полностью на русском языке, так как это основной язык пользователя.
- **Производительность:** Использование отдельного потока для захвата кадров и обработки MediaPipe, чтобы избежать зависаний GUI.
